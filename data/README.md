# Dataset Documentation

## Overview

This folder contains the CSV dataset used by the machine-learning component of the project.

## File

`data.csv`

## Dataset Information

* Total records: 1,255
* Total columns: 4
* Input features: 3
* Target column: `RES`
* Missing values in the supplied dataset: 0

## Column Descriptions

| Column | Role   | Description                    |
| ------ | ------ | ------------------------------ |
| `R`    | Red Light Intensity  | This represents the raw digital value or sensor reading of Red light (typically around 660 nm) |
| `IR`   | Infrared Light Intensity | This represents the raw digital value or sensor reading of Infrared light (typically around 940 nm) |
| `G`    | Glucose Level | This represents the target Blood Glucose concentration |
| `RES`  | Result | Classification readings    |
