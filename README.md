# Non-Invasive Glucose Monitoring Using Raspberry Pi and Machine Learning

A Raspberry Pi-based prototype exploring optical sensing and machine learning for non-invasive glucose monitoring.

## Overview

This project explores the integration of optical sensing, machine learning and embedded hardware to investigate glucose-related classification from optical measurements.

The prototype uses a Raspberry Pi for data processing, a MAX30102 pulse-oximeter sensor as described in the project design, an LCD for displaying outputs, and a GSM modem for SMS communication.

The machine-learning component compares K-Nearest Neighbors (KNN), Support Vector Classifier (SVC) and Logistic Regression using tabular sensor-related features.

**Project status:** Prototype / research project. Glucose values generated by the original demonstration code are simulated and are not clinical measurements or validated glucose predictions.

## Dataset

The supplied CSV contains 1,255 records and the following columns:

| Column | Role                                               |
| ------ | -------------------------------------------------- |
| `R`    | The raw digital value of Red light                 |
| `IR`   | The raw digital value of Infrared light            |
| `G`    | Target Blood Glucose concentration                 |
| `RES`  | Target classification label                        |

The current implementation uses `R`, `IR` and `G` as features and `RES` as the target.

The dataset contains five distinct target labels: 0, 1, 2, 3 and 4. Their clinical interpretation must be documented from the original data collection protocol rather than assumed.

Before using this dataset for research, document its source, collection procedure, units, participant information where applicable, and whether the values are measured, derived or simulated.

## Machine-Learning Methodology

1. Load the CSV dataset.
2. Separate the input features from the target column.
3. Split the data into training and testing subsets.
4. Train a KNN classifier using four neighbors.
5. Train an SVC model.
6. Train a Logistic Regression model.
7. Compare classification performance on the test set.
8. Visualize the results.
9. Use the trained KNN classifier for the prototype's classification workflow.

## Installation

Clone the repository:

```bash
git clone https://github.com/harshi43596/Non-Invasive-Glucose-Monitoring-
cd non-invasive-glucose-monitoring
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the offline model-training script:

```bash
python src/train_model.py
```

The Raspberry Pi hardware application requires compatible GPIO hardware, a correctly configured serial interface and the appropriate device libraries.

## Limitations

* The current implementation performs classification rather than directly predicting a numerical glucose concentration.
* The original live demonstration generates random glucose values based on the predicted class.
* The clinical meaning and provenance of the target labels require confirmation.
* Sensor readings can be affected by acquisition conditions and signal quality.
* The current code does not establish clinical accuracy or safety.
* Further validation against reference glucose measurements is required before making medical claims.
